## 📊 Understanding Technical Analysis

### RSI (Relative Strength Index)
**What it measures:** Momentum - is a crypto overbought or oversold?

| RSI Value | Meaning | Action |
|-----------|---------|--------|
| 70+ | Overbought 📈 | Consider taking profits |
| 30-70 | Neutral 😐 | Wait for clear signals |
| <30 | Oversold 📉 | Potential buying opportunity |

**Example Output:**
```
• RSI (14): 75 - Overbought → Consider taking profits
```

### Moving Averages
**What they show:** Trend direction and momentum

| Position | Meaning | Implication |
|----------|---------|-------------|
| Price above MA | Bullish 📈 | Upward momentum |
| Price below MA | Bearish 📉 | Downward pressure |
| MA crossing | Trend change | Watch for confirmation |

### Volume Analysis
**What it confirms:** Whether price moves are legitimate

| Volume Trend | With Price Up | With Price Down |
|--------------|---------------|-----------------|
| Increasing ⬆️ | Strong bullish signal | Strong bearish signal |
| Decreasing ⬇️ | Weak move, might reverse | Weak move, might bounce |
| Stable ➡️ | Moderate confidence | Moderate confidence |

## 💼 Portfolio Management Guide

### Method 1: Screenshot Import (Recommended)

**Step 1:** Take a clear screenshot of your CoinStats portfolio
- Ensure coin symbols (BTC, ETH, etc.) are visible
- Make sure amounts are clearly shown
- Include current values if possible

**Step 2:** Upload to Claude and say:
```
Update my portfolio from this screenshot
```

**Step 3:** Claude will analyze and extract:
- Coin symbols and amounts
- Current values (fetched in real-time)
- Performance calculations

### Method 2: Manual Entry (Backup)

**Format:** `SYMBOL:AMOUNT:PURCHASE_PRICE`

**Example:**
```
Update my portfolio manually: BTC:0.5:28000,ETH:2:3200,ADA:1000:1.50
```

This means:
- 0.5 Bitcoin bought at €28,000 each
- 2 Ethereum bought at €3,200 each  
- 1,000 Cardano bought at €1.50 each

## 🔧 Troubleshooting Common Issues

### "I don't see the crypto-investment MCP"

**Solution:**
1. Check Claude Desktop integration menu (hambumburger icon)
2. Restart Claude Desktop completely
3. Verify config file path is correct
4. Test MCP server runs independently: `node src/index.js`

### "Portfolio update isn't working"

**For Screenshots:**
- Ensure coin symbols are clearly visible
- Try different angles or zoom levels
- Use manual method as backup

**For Manual Entry:**
- Check format: `SYMBOL:AMOUNT:PRICE` (no spaces around colons)
- Use common symbols: BTC, ETH, ADA, SOL
- Separate multiple entries with commas

### "API errors or slow responses"

**Solutions:**
- Check internet connection
- Wait 1-2 minutes (might be rate limiting)
- Try simpler commands first
- Restart the MCP server if needed

### "Prices seem wrong"

**Check:**
- EUR vs USD confusion (we default to EUR)
- Market volatility causing rapid changes
- Compare with CoinGecko.com for verification

## 🎓 Learning Resources

### Understanding Crypto Analysis

**RSI Deep Dive:**
- Developed by J. Welles Wilder Jr.
- Measures speed and magnitude of price changes
- Most effective in ranging markets
- Can give false signals in strong trends

**Moving Averages Explained:**
- Simple average of prices over X days
- 20-day = short-term trend
- 50-day = medium-term trend
- 200-day = long-term trend (not included in our analysis)

**Volume Analysis:**
- High volume + price increase = strong bullish signal
- High volume + price decrease = strong bearish signal
- Low volume + any price move = weak signal, likely to reverse

### Investment Terminology

**Market Cap:** Total value of all coins in circulation
**24h Volume:** Total EUR value traded in 24 hours
**Support:** Price level where buying typically emerges
**Resistance:** Price level where selling typically emerges
**Bull Market:** Extended period of rising prices
**Bear Market:** Extended period of falling prices
